# Inter UI font

Unmodified `InterVariable.ttf` from the Inter project:
https://github.com/rsms/inter/tree/353b61b9f4430d5f420d56605a6e7993e0941470

Source file: `docs/font-files/InterVariable.ttf`.
SHA-256: `4989b125924991b90d05b2d16e0e388c48f7d5bb8b30539bbf9c755278d0ccaf`.
License/copyright: [INTER-LICENSE.txt](INTER-LICENSE.txt), SIL Open Font License 1.1.

On Linux the GUI registers this font privately with Fontconfig for its process.
It does not install system/user fonts. Platforms without supported registration
use an available native sans-serif font. Diagnostic/code output stays monospace.

Unmodified `selawk.woff2`, `selawksb.woff2` and `selawksl.woff2` from Microsoft's open-source Selawik release 1.01

`Selawik-Regular.woff2`, `Selawik-Semibold.woff2` and `Selawik-Semilight.woff2`. Selawik is the open-source
stand-in for Segoe UI; the Windows device pages use it.
